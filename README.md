Tech Stack: React, Tailwind CSS, Python, FastAPI, LangGraph, OpenAI LLM, Supabase





Built an AI-powered chatbot using FastAPI and LangGraph to process user inputs (age, income, location) and recommend relevant welfare schemes, improving information accessibility.



Implemented LLM-driven eligibility assessment and automated guidance, reducing manual search effort by ~40% (tested on 20+ sample cases).



Developed a responsive frontend in React and integrated Supabase (PostgreSQL) with webhook-based workflows for real-time data handling.



Defined product strategy using Lean Canvas and Concept Note, aligning solution design with stakeholder requirements and scalability goals.
